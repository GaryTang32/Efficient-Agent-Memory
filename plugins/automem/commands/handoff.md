Write a concise handoff recap of this session for whoever continues the work in a new session, then stop. Use these
six fields, with exact paths, identifiers, commands and numbers:

1. Objective - one line describing the required result.
2. Established facts - observations, separated from unverified ideas.
3. Applied changes - each changed or created file, what changed, and whether it was verified.
4. Verification - exact checks run and their outcomes.
5. Dead ends - approaches that failed and should not be repeated.
6. Remaining plan - outstanding subgoals in order, the immediate next command or edit, and the condition for
   completion.
